## This year's theme: online safety

Every 2026 project teaches something about staying safe online: spotting a phishing link, working out which downloads are safe, deciding what not to put in a photo, and building an encrypted handshake between two devices.

The idea is to turn kids from passive users into active defenders. They code the solution rather than sit through a lecture about it.

## How the day runs

{{< steps >}}
{{< step number="1" title="10am — sign in and set up" >}}
Arrive at the hall, grab a spot and get your laptop on the wifi. Leaders will help anyone who needs a machine sorted.
{{< /step >}}
{{< step number="2" title="Pick a project" >}}
Choose one of the seven projects below. Newer coders should start with Scratch; the instructions are translated into a stack of languages if that helps.
{{< /step >}}
{{< step number="3" title="Build it, then break it" >}}
Work through the instructions at your own pace, then innovate: new sprites, extra levels, harder gameplay. The judges reward projects that go past the original.
{{< /step >}}
{{< step number="4" title="Submit it (optional)" >}}
Share Scratch projects, or upload the Python and micro:bit files, on the Moonhack submission page. Australian entries go into the prize categories.
{{< /step >}}
{{< step number="5" title="3pm — show and tell" >}}
Demo what you made to the room, then pack up and head home.
{{< /step >}}
{{< /steps >}}

## The seven projects

{{< alert icon="circle-info" >}}
Project names and details come from Code Club Australia's 2026 comms pack. Starter links go up on [moonhack.com](https://moonhack.com) as each project is released.
{{< /alert >}}

{{< feature-grid columns="4" >}}
{{< feature icon="eye" title="Priva-See Detective" headingLevel="h3" >}}
What is safe to include in a photo you share? Find what should not be in shot. **Scratch, beginner.**
{{< /feature >}}
{{< feature icon="shield" title="Cyber Safety Mission" headingLevel="h3" >}}
A quiz on safe choices online — sharing names, addresses, meeting up in real life. **Scratch, beginner to intermediate.**
{{< /feature >}}
{{< feature icon="bug" title="Whack the Hack" headingLevel="h3" >}}
Whack-a-mole, but only the safe downloads. Clones, variables and multiple conditions. **Scratch, mid to advanced.**
{{< /feature >}}
{{< feature icon="globe" title="Safe Site Sprint" headingLevel="h3" >}}
A platformer where you collect only the safe websites. Custom blocks and sensing. **Scratch, mid to advanced.**
{{< /feature >}}
{{< feature icon="lock" title="Identity Guard" headingLevel="h3" >}}
Two micro:bits simulate an encrypted handshake to verify a digital identity. **micro:bit, beginner.**
{{< /feature >}}
{{< feature icon="search" title="Phishy Finder" headingLevel="h3" >}}
Read a URL closely enough to spot the phishy ones. Lists, dictionaries and scoring. **Python.**
{{< /feature >}}
{{< feature icon="wand-magic-sparkles" title="AI: avatar or photo?" headingLevel="h3" >}}
Train a model to tell an avatar from a real photo, and learn why an avatar is the safer choice. **Teachable Machine, all levels.**
{{< /feature >}}
